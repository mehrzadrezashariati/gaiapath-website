# GAIA PATH website

Static website for [www.gaiapath.ai](https://www.gaiapath.ai): independent advisory for AI-supported decisions in business, government and non-profit organizations.

- Plain HTML, CSS and JavaScript, no build step. Open `index.html` in a browser to preview.
- Bilingual (EN/DE): all texts live in `app.js` (main page) and `founder.js` (founder essay).
- `impressum.html`: legal notice and privacy information.
- Fonts are self-hosted in `assets/fonts/` (no third-party requests).
- Hosted on GitHub Pages; `CNAME` points the site to www.gaiapath.ai.
